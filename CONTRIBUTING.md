# Contributing

Thank you for helping.

## Where to change things

| I want to change | Edit |
| --- | --- |
| The start page | [README.md](README.md) |
| Setup steps | The guide for that connection method in [docs/](docs/development.md#layout) |
| Server addresses, tools, or sign-in | [docs/mcp/](docs/mcp/endpoints.md) |
| A Claude plugin or skill | Its folder under `integrations/claude/`. Read the [development guide](docs/development.md) first. |
| The Gemini extension | [gemini-extension.json](gemini-extension.json) and [JOTFORM.md](JOTFORM.md) |

## Rules

- Write short, plain sentences.
- Keep each setup in one guide. Other pages link to it.
- Only describe what Jotform has published.

## Before you open a pull request

Follow [Check your change](docs/development.md#check-your-change). Write the AI tool version and the result in the pull request.

## Report a problem

[Open an issue](https://github.com/jotform/mcp-server/issues). Say which guide or plugin, which AI tool and version, what you expected, and what happened. Do not include passwords or private data.

For account problems, contact [Jotform Support](https://www.jotform.com/answers/).
