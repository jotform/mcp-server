# Jotform

Use the connected `jotform` MCP server to help the user find, create, and edit forms and work with submissions.

## Working with Jotform

- Use the connected server's tool definitions for available operations and required arguments.
- Find an existing form with the server's search or listing tools, or use the identifier supplied by the user.
- Use the server's returned form identifiers and links in follow-up operations and replies.
- If authentication is required, direct the user to `/mcp auth jotform` in Gemini CLI.
- Summarize the result of each requested operation and provide the returned link when available.
