# Find and list forms

Use tools from the `jotform` connector. When another connector exposes the same short tool name, choose the tool that belongs to `jotform`. Treat the connected server's current tool definitions as the contract. If the connector is unavailable, name the connection the user needs. Never ask for a password or token in chat.

1. Use this connector's `search` with the user's terms, and answer from its results. Do not repeat every title, ID and link unless the user asks for a text list or needs those details.
2. When the user wants to act on one form and more than one match is plausible, ask which one. If nothing matches, say so.

## Reply

Keep the reply short.
